# SellPilot — MVP

Prototype front-end d'un SaaS d'aide à la création d'annonces.

## Ce qui fonctionne
- landing page
- interface mobile/desktop
- upload d'une photo
- aperçu de la photo
- génération simulée d'une annonce
- bouton copier
- page tarifaire à 14,99 €/mois

## Prochaine étape pour passer au vrai produit
1. Brancher une API de vision/LLM.
2. Ajouter authentification.
3. Ajouter Stripe pour l'abonnement.
4. Ajouter base de données et historique.
5. Ajouter estimation de prix basée sur des données de marché.
6. Déployer le site.

Le prototype ne publie rien automatiquement sur les marketplaces.
